시멘틱 HTML이란?

Semantic = 의미론적, 의미가 있는

HTML 요소가 그 내용의 의미를 명확하게 표현하는 것

📌 왜 중요한가?

  • 검색엔진 최적화(SEO): 검색엔진이 콘텐츠를 더 잘 이해
  • 접근성: 스크린 리더가 구조를 파악하여 정확히 전달
  • 유지보수: 코드의 의미가 명확해 협업이 쉬움
  • 표준화: 웹 표준을 따라 모든 브라우저에서 일관성 유지
2 / 10

시멘틱 vs 논시멘틱 비교

❌ 논시멘틱 (나쁜 예)
<div id="header">
  <div class="logo">로고</div>
</div>
<div id="nav">
  <div>메뉴1</div>
</div>
<div id="content">
  <div class="post">
    <div class="title">제목</div>
  </div>
</div>
<div id="footer">푸터</div>
✅ 시멘틱 (좋은 예)
<header>
  <h1>로고</h1>
</header>
<nav>
  <ul><li>메뉴1</li></ul>
</nav>
<main>
  <article>
    <h2>제목</h2>
  </article>
</main>
<footer>푸터</footer>
3 / 10

주요 시멘틱 요소

  • <header> - 페이지나 섹션의 머리말
  • <nav> - 네비게이션 링크 그룹
  • <main> - 문서의 주요 콘텐츠 (페이지당 1개)
  • <article> - 독립적인 콘텐츠 (뉴스, 블로그 글)
  • <section> - 주제별 콘텐츠 그룹
  • <aside> - 보조 콘텐츠 (사이드바, 광고)
  • <footer> - 페이지나 섹션의 바닥글
  • <figure> / <figcaption> - 이미지와 캡션

WAI-ARIA란?

Web Accessibility Initiative - Accessible Rich Internet Applications

시멘틱 HTML만으로 표현하기 어려운 동적 콘텐츠와
복잡한 UI 컴포넌트의 접근성을 개선하는 기술

🎯 ARIA의 핵심 개념

  • Role: 요소의 역할 정의 (button, dialog, tab 등)
  • Properties: 요소의 특성 (label, required 등)
  • States: 요소의 상태 (expanded, checked 등)

⚠️ 중요 원칙: 시멘틱 HTML이 우선! ARIA는 보완 수단

6 / 10

주요 ARIA 속성

1. role 속성

<div role="button">클릭하세요</div>
<div role="navigation">...</div>
<div role="alert">오류 발생!</div>

2. aria-label (보이지 않는 레이블)

<button aria-label="메뉴 닫기">✕</button>
<input type="search" aria-label="사이트 검색">

3. aria-labelledby (다른 요소 참조)

<h2 id="dialog-title">알림</h2>
<div role="dialog" aria-labelledby="dialog-title">
  내용...
</div>
7 / 10

ARIA 상태(State) 속성

동적 변화를 나타내는 속성들

<!-- 확장/축소 -->
<button aria-expanded="false" aria-controls="menu">
  메뉴
</button>
<ul id="menu" hidden>...</ul>

<!-- 선택 상태 -->
<button role="tab" aria-selected="true">탭1</button>

<!-- 체크 상태 -->
<div role="checkbox" aria-checked="true">동의함</div>

<!-- 비활성화 -->
<button aria-disabled="true">전송</button>

<!-- 숨김 -->
<div aria-hidden="true">스크린리더에서 숨김</div>
8 / 10

✅ 실무 체크리스트

시멘틱 HTML

  • div 대신 적절한 시멘틱 태그 사용했는가?
  • heading(h1~h6)이 순서대로 사용되었는가?
  • 이미지에 alt 속성이 있는가?
  • form 요소에 label이 연결되어 있는가?

WAI-ARIA

  • 시멘틱 HTML로 해결 가능한지 먼저 확인했는가?
  • 동적 콘텐츠에 적절한 role이 부여되었는가?
  • 상태 변화를 aria 속성으로 표현했는가?
  • 키보드로 모든 기능을 사용할 수 있는가?

📦장바구니란?

장바구니(Shopping Cart)는 온라인 쇼핑몰에서 구매할 상품을 임시로 담아두는 기능입니다.

주요 기능

  • 상품 추가: 원하는 상품을 장바구니에 담기
  • 수량 조절: 상품 개수 증가/감소
  • 상품 삭제: 장바구니에서 상품 제거
  • 금액 계산: 총 가격 자동 계산
  • 데이터 저장: 새로고침 후에도 데이터 유지

🗂️데이터 구조 설계

장바구니의 상품 정보를 JavaScript 배열과 객체로 관리합니다.

const cart = [
  {
    id: 1,
    name: "노트북",
    price: 1200000,
    quantity: 1,
    image: "laptop.jpg"
  },
  {
    id: 2,
    name: "마우스",
    price: 35000,
    quantity: 2,
    image: "mouse.jpg"
  }
];

각 상품은 고유 ID, 이름, 가격, 수량, 이미지 정보를 포함합니다.

⚙️JavaScript - 상품 추가

장바구니에 상품을 추가하는 함수입니다.

function addToCart(product) {
  const existing = cart.find(item => item.id === product.id);
  
  if (existing) {
    existing.quantity += 1; // 이미 있으면 수량 증가
  } else {
    cart.push({...product, quantity: 1}); // 새로 추가
  }
  
  updateCartDisplay(); // 화면 업데이트
  saveCart(); // 저장
}

중복 체크 후 수량만 증가시키거나 새로 추가합니다.

🔧JavaScript - 총 금액 계산

장바구니의 총 금액을 계산하는 함수입니다.

function calculateTotal() {
  const total = cart.reduce((sum, item) => {
    return sum + (item.price * item.quantity);
  }, 0);
  
  document.getElementById('total').textContent =
    total.toLocaleString();
  
  return total;
}

reduce() 메서드로 각 상품의 가격×수량을 모두 합산합니다.

💾데이터 저장 - localStorage

새로고침 후에도 장바구니 데이터를 유지하는 방법입니다.

// 저장
function saveCart() {
  localStorage.setItem('cart', JSON.stringify(cart));
}

// 불러오기
function loadCart() {
  const saved = localStorage.getItem('cart');
  if (saved) {
    cart = JSON.parse(saved);
    updateCartDisplay();
  }
}

브라우저에 데이터를 저장하여 영구 보관합니다.
